# Little Ganesha Tarot — V0.9.1 Lucky Numbers Polish

**Studio:** Benedict Interactive  
**Target runtime:** V0.9.1  
**Baseline runtime:** V0.9.0  
**Baseline GitHub HEAD:** `505e099ca21e229f67bebe84779360ee369ac042` — `Add Lucky Numbers V0.9.0`  
**Reading Engine:** 1.1.0 (unchanged)  
**Deck Ritual:** 1.1.0 (unchanged)

## What changes

V0.9.1 refines Lucky Numbers after real-device review while preserving the daily one-set contract.
The candidate pool expands from **1–9 to 0–9**, the oracle chamber now contains ten crystal orbs,
and zero receives complete English, Thai and Hindi symbolic interpretation.

The result view also adds a restrained **Today's Number Set / ชุดเลขของวันนี้ / आज के अंक-संयोजन**
section. It derives a small set of single-, pair- and three-digit forms from the three already-fixed
daily digits. These are presented as symbolic forms for everyday contexts, never as lottery picks,
betting combinations or predictions.

## Numeral legibility

The numeral glyph inside every Lucky Numbers orb now uses a dedicated lining-numeral serif stack
(`Georgia` / `Times New Roman`) instead of inheriting the decorative brand display face. This makes
**1 visibly read as the digit 1 rather than the letter I** while retaining the brass-and-crystal
premium aesthetic. The same numeral treatment is used in the kinetic machine, result cards,
number-set chips and Save/Share artwork.

## Exit and replay usability

Lucky Numbers now provides an explicit localized **Back to Home** action below the oracle and again
at the end of a completed result. The first action remains available while a replay animation is
running, so a user is never trapped in the replay view. The original top-left back control remains.
Replay still replays presentation only and never changes the stored daily numbers.

## Daily contract

- Candidate pool: integers **0–9**.
- Daily result: exactly three unique digits.
- Roles remain Core / Supporting / Balancing.
- Selection is created only when the user deliberately begins the reveal.
- `crypto.getRandomValues()` with rejection sampling is used when available.
- Once created, the set is fixed for the current device-local day.
- Interrupted reveals restore the same set; replay cannot reroll it.
- Existing valid V0.9.0 same-day records remain valid and are not regenerated by this patch.

## Native languages

English, Thai and Hindi remain first-class across UI, number meanings, the combined daily pattern,
number-set labels/explanations, accessibility text, exit controls and Save/Share artwork.
The canonical `LITTLE GANESHA TAROT / THE GOLDEN PATH` brand lockup remains unchanged.

## Protected behavior

V0.9.1 does not change Reading Engine 1.1.0, Deck Ritual 1.1.0, canonical 78-card IDs/artwork,
pre-shuffle/prebound tarot selection, Daily/Ask persistence, Signature Focus locks, Hindi Ask
semantics, existing tarot Save/Share, audio lifecycle, card viewers or universal app icons.

## Runtime coherence

The PWA build/cache identity moves coherently to V0.9.1: HTML asset query strings, manifest icon
references, `window.LGT_BUILD`, visible build label, Service Worker build/cache IDs and app-shell
URLs all move together. Because Service Worker identity changes, deployment remains operationally
HIGH risk even though the functional changes are isolated to Lucky Numbers.

## Acceptance

Static/package QA passes. **Real-device V0.9.1 acceptance remains required** for the ten-orb machine,
zero selection, digit-1 legibility, replay exit controls, EN/TH/HI layout, Today's Number Set,
Save/Share artwork, local-day persistence and PWA cache activation.
