# Release Notes — V0.6.2

## Golden Path editorial reading layout

V0.6.2 refines the revealed-card presentation in The Golden Path after real-device review identified an imbalance between card artwork and long-form consultation copy.

### Changed

- Golden Path no longer uses the narrow side-by-side artwork/copy presentation inherited from Three-Card Reading.
- Each revealed card is presented as one full-width editorial block.
- Position label appears first, followed by centered artwork and card identity.
- The interpretation runs at full width beneath the card identity for substantially better Thai and English reading comfort.
- Typography, spacing, dividers, and artwork scale are tuned for mobile reading.
- The magnifier cue remains available but carries less visual weight.
- Wider screens keep Golden Path cards one-per-row because the mode contains long consultation copy.

### Unchanged

No tarot selection, narrative, storage, countdown, Save/Share, viewer behavior, Reading Engine, Deck Ritual, Daily Guidance, Ask Ganesha, or Three-Card logic is changed by this release.

### Runtime

Runtime and cache identity move coherently from V0.6.1 to V0.6.2 so installed PWA clients receive the new Golden Path stylesheet reliably.
