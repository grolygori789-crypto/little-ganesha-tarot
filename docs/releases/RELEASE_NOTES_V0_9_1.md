# Release Notes — V0.9.1

## Lucky Numbers polish

- Expands the Lucky Numbers pool from `1–9` to **`0–9`** with ten visible machine orbs.
- Adds native English, Thai and Hindi symbolic guidance for **0**.
- Adds a curated **Today's Number Set / ชุดเลขของวันนี้ / आज के अंक-संयोजन** derived from the fixed daily digits.
- Replaces the decorative orb numeral face with a dedicated lining-numeral serif treatment so **1 reads clearly as 1, not I**.
- Applies the numeral fix consistently to the kinetic machine, result cards, number-set chips and Save/Share artwork.
- Adds explicit localized **Back to Home** controls that remain available during replay and at the completed result.
- Replay still cannot reroll the daily result; existing V0.9.0 same-day records remain valid.
- PWA build/cache identity moves coherently to V0.9.1.

No tarot-selection, Reading Engine, Deck Ritual, audio-lifecycle or existing tarot Save/Share behavior is changed.
