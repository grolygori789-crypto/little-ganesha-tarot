# Little Ganesha Tarot V0.11.1 — Journal Numeral Polish

V0.11.1 fixes a typography issue found during real-device review of the new Private Journal.

## Fixed

- Journal count digit **1** now uses a dedicated lining-numeral serif stack and no longer resembles uppercase **I**.
- The treatment is applied consistently to Journal summary counters, per-day saved-entry counts, card-count labels, calendar numeric markers, pattern/monthly count summaries and multi-select count.

## Unchanged

Journal IndexedDB data, automatic capture, reflections, bookmarks, single/bulk deletion, re-capture suppression, privacy defaults, source reading locks, tarot selection, Lucky Numbers generation, Save/Share, audio lifecycle and Tarot Library behavior are unchanged.

Because the PWA Service Worker/cache identity moves, deployment is operationally HIGH risk even though the functional change is LOW risk.
