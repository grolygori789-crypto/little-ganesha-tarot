# Release Notes — V0.12.0

## Reading Hub

The bottom **Read** tab is now a dedicated premium Reading Hub. Users can choose a reading directly or begin from what they need today and receive a clear non-automatic suggestion among Daily Guidance, Ask Ganesha, Three-Card Reading, The Golden Path and Remove the Obstacle.

The Hub surfaces existing same-day status and Focus progress without changing tarot state. No new randomization, card-selection behavior, daily rule or persistence schema is introduced.

English, Thai and Hindi are included. Runtime/PWA cache identity moves coherently to V0.12.0.
