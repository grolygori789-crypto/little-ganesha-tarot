# V0.8.0 — Native Hindi Launch

V0.8.0 adds Hindi (हिन्दी) as Little Ganesha Tarot's third supported language.

### Added
- Hindi language option on title screen and Settings.
- Native Hindi home/onboarding/profile/audio/settings copy.
- 78-card Hindi tarot content with Hindi titles, keywords, meanings, reflections and contextual lenses.
- Hindi-aware Ask Ganesha analysis, semantic same-day restore, and safety boundaries.
- Native Hindi integrated readings for Three-Card, Golden Path and Remove the Obstacle across all six Focuses.
- Hindi Save/Share rendering.
- Devanagari typography and spacing support.

### Preserved
- Reading Engine 1.1.0 and Deck Ritual 1.1.0.
- Existing English and Thai content/behavior.
- 78-card selection integrity and no-reroll semantics.
- Per-Focus one-completed-reading-per-local-day behavior.
- Audio lifecycle, card viewers, universal icon system and PWA architecture.

### Acceptance status
Static/package QA passes. Real-device Hindi acceptance is pending.
