# Release Notes — V0.4.8 Premium Home Profile

V0.4.8 adds a premium age-and-zodiac line under the existing Home greeting.

## Added

- Exact calendar age: years, months, and days.
- Automatic Western/Tropical zodiac from the saved birth date.
- Native Thai and English presentation.
- Premium responsive styling in an isolated Home-profile stylesheet.
- Automatic refresh after profile/language changes, app resume/focus, and local midnight.

## Privacy

No new personal data is collected. Age and zodiac are computed locally from the existing birth-date field and are not persisted separately.

## Protected

Reading Engine, Daily Guidance, Ask Ganesha semantics, Save/Share, audio, and tarot content are unchanged.
