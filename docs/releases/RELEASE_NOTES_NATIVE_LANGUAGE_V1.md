# Native Language V1 — English + Thai

Goal: users should understand the message on the first read and know what to do next.

Coverage:
- Main menu, onboarding, settings and profile
- Daily Guidance: all 78 cards plus all six context lenses
- Ask Ganesha: answer, reason, real-world check, next action, reflection
- 3-Card Reading: positions, summary, most important issue, next action
- The Golden Path: positions, summary, best way forward, action list
- Remove the Obstacle: problem, what keeps it going, what helps, actions
- Lucky Numbers: screen copy and number meanings 0–9
- Tarot Guide: navigation/card/about wording
- Journal: navigation, privacy, notes, empty states and deletion wording

English and Thai are written for natural everyday use, not literal translation.
Hindi is intentionally unchanged.

Runtime invariants preserved:
Reading Engine, Deck Ritual, daily locks, storage, animations, audio,
Ko-fi/PromptPay, zoom lock, portrait lock and service worker are unchanged.
