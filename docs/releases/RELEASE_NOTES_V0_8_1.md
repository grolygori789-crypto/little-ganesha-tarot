# V0.8.1 — Brand Title Consistency

V0.8.1 is a narrow visual hotfix for the Hindi title screen.

## Changed

- Restores the canonical Cormorant Garamond brand typeface for `LITTLE GANESHA / TAROT` when Hindi is active.
- Keeps all Hindi-localized UI and reading typography in the existing Devanagari font system.
- Moves runtime/cache markers from 0.8.0 to 0.8.1 for coherent PWA delivery.

## Unchanged

- English and Thai title presentation.
- Hindi copy and localization content.
- All five reading modes and their narratives.
- Reading Engine 1.1.0 and Deck Ritual 1.1.0.
- Selection, persistence, Focus locks, Save/Share, audio, viewers, icons and card artwork.
