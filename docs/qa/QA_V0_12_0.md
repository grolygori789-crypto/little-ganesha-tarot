# QA — V0.12.0 Reading Hub

## Required automated/static gates

- `node --check js/read-hub.js`
- HTML contains `css/read-hub.css?v=0.12.0` and `js/read-hub.js?v=0.12.0`.
- No `0.11.1` runtime residue in index, app build marker, manifest or Service Worker.
- Service Worker build is 0.12.0 and caches both Reading Hub assets.
- Hub captures only `[data-feature="read"]` and opens existing public reading APIs.
- Hub has no card-selection RNG and does not call protected storage save/clear methods.
- Intent selection highlights a recommendation but does not launch automatically.
- Status reads Daily/Ask/Focus state without mutation.
- EN / TH / HI copy is present.
- Escape, Back and Home close the Hub.
- Reduced-motion path removes animated transitions / smooth scroll.
- Package SHA-256 verification passes after fresh extraction.

## Real-device acceptance still required

Android/iOS/PWA behavior must not be inferred from static QA. Verify bottom Read navigation, safe areas, layout, all five launches, return behavior, language switching, status refresh and cache activation on real devices.
