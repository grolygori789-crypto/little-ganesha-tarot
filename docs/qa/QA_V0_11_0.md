# QA — V0.11.0 Private Journal

## Automated/static release gates

- [x] New Journal JavaScript parses with Node syntax checks.
- [x] Modified `js/app.js` and `sw.js` parse successfully.
- [x] `manifest.webmanifest` and patch manifest parse as valid JSON.
- [x] Runtime build/cache/query markers are coherent at V0.11.0.
- [x] Journal CSS/JS are present in HTML and the Service Worker application shell.
- [x] Journal uses a capture-phase `data-feature="journal"` handler so the old generic placeholder
      toast cannot win the click.
- [x] Journal persistence is isolated in IndexedDB; no Journal delete path calls protected reading
      storage deletion/reset APIs.
- [x] Deleted entry identities are suppressed from automatic re-capture.
- [x] Exact Ask question storage defaults OFF.
- [x] Single delete, bulk delete and two-stage clear flows require confirmation.
- [x] Timeline/calendar use canonical card artwork rather than duplicating card media.
- [x] Search, mode filters, bookmark filter, calendar month navigation and entry detail are present.
- [x] EN / Thai / Hindi Journal copy sets are complete at the product layer.
- [x] Reduced-motion CSS path is present.

## Browser interaction checks

Browser/harness QA should verify:

1. Journal opens from Home and bottom navigation instead of showing Coming soon.
2. Empty Journal renders correctly.
3. Seeded entries render in timeline and calendar.
4. Entry detail shows card/number visuals and saved snapshot sections.
5. Reflection edit persists and adds calendar reflection state.
6. Bookmark toggles and filter works.
7. Select mode supports multiple entries and bulk delete.
8. Single delete removes only Journal content and does not affect source reading state.
9. Clear Journal Data requires both confirmation stages.
10. Switching EN / Thai / Hindi rerenders Journal UI without corrupting stored snapshots.
11. 390×844 mobile viewport has no horizontal overflow.

## Real-device acceptance still required

Static/headless checks do not establish Android+iOS acceptance. On a real device verify:

- automatic capture after each completed mode;
- restoration/reopening does not duplicate entries;
- exact Ask question privacy ON/OFF behavior;
- deletion remains deleted while the source daily result remains locked;
- timeline/calendar scrolling and safe areas;
- textarea keyboard behavior;
- bulk selection ergonomics;
- PWA update from V0.10.0 to V0.11.0;
- background/foreground audio behavior remains unchanged.
