# QA — V0.8.1 Brand Title Consistency

## Scope

One presentation defect: Hindi locale inherited `Noto Serif Devanagari` through the broad
`html[lang="hi"] h1` rule, causing the English `LITTLE GANESHA / TAROT` brand masthead to change
typeface. The fix adds a more-specific title-lockup rule that restores the canonical brand font.

## Static checks

- PASS — Hindi title masthead override targets `.title-lockup h1` only.
- PASS — Canonical font stack is `"Cormorant Garamond", Georgia, serif`.
- PASS — Existing Hindi body/UI/reading Devanagari rules remain intact.
- PASS — No Reading Engine or Deck Ritual source changes.
- PASS — Runtime markers and asset query strings are 0.8.1.
- PASS — `window.LGT_BUILD` is 0.8.1.
- PASS — Service Worker BUILD/cache/application-shell URLs are 0.8.1.
- PASS — Manifest icon cache-bust references are 0.8.1.
- PASS — JavaScript syntax check for `js/app.js` and `sw.js`.
- PASS — Package re-extract and SHA-256 verification.

## Real-device acceptance checklist

1. Open title screen in EN and confirm the existing `LITTLE GANESHA / TAROT` appearance is unchanged.
2. Switch to ไทย and confirm the brand masthead remains unchanged.
