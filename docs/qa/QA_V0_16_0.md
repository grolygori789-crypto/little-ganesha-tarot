# QA — V0.16.0

## Scope

Worldwide Ko-fi support activation and support UX only.

Buy Me a Coffee is no longer the selected worldwide provider. Ko-fi is the accepted provider for this release.

## Static checks

- Official destination is exactly `https://ko-fi.com/benedictinteractive`.
- Worldwide Settings card is enabled and no longer displays `Coming soon`.
- Ko-fi card/sheet copy exists for EN / TH / HI.
- External CTA uses a direct user-initiated link.
- External CTA uses `target="_blank"` plus `rel="noopener noreferrer external"`.
- No query parameters containing reading/profile/Journal data are appended.
- No payment callback/backend/entitlement code is introduced.
- PromptPay QR path, recipient names and save behavior remain unchanged.
- Opening support does not call Reading Engine, Ask storage, Focus storage, Lucky storage or Journal APIs.
- `js/support.js` syntax passes.
- `manifest.webmanifest` parses as JSON.
- `PATCH_MANIFEST_V0_16_0.json` parses as JSON.
- HTML metadata/body/build label and asset query strings are V0.16.0.
- `js/support.js` finalizes live `window.LGT_BUILD` as V0.16.0 after `js/app.js` initializes.
- Service Worker BUILD/cache identity and app-shell query strings are V0.16.0.
- Manifest icon query strings are V0.16.0.
- Legal acknowledgement version remains 1.0.0.

## Support regression

### Worldwide / Ko-fi

Verify:

1. Settings → Support the Project shows Worldwide active.
2. Card label identifies Ko-fi.
3. Open Ko-fi opens the in-app support sheet.
4. Back returns focus to the Worldwide button.
5. Home closes the sheet and returns Home.
6. Escape closes the sheet in keyboard-capable browser.
7. Language changes update card + sheet in EN / TH / HI.
