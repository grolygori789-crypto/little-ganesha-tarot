# QA — V0.6.1 Golden Path Hotfix

## Defect reproduction from V0.6.0

Observed on real device:

- the 78 Golden Path facedown choices rendered broken-image placeholders;
- after the first choice, cards 2 and 3 could not be selected.

## Root-cause verification

V0.6.0 Golden Path omitted Deck Ritual options required by a three-card full-deck spread. Deck Ritual therefore used its safe defaults: empty card-back URL and selection limit of one.

## Static gates

- `js/golden-ui.js` parses successfully;
- Golden Path Deck Ritual call explicitly supplies `CONTENT.cardBack`;
- candidate count is bound to `candidates.length`;
- `selectionLimit` is exactly 3;
- row count is 6;
- variant is `full`;
- Reading Engine and Deck Ritual source files are untouched;
- `index.html`, `js/app.js`, and `sw.js` use runtime 0.6.1 coherently;
- Service Worker app-shell URLs use 0.6.1 consistently;
- no `?v=0.6.0` live query remains in index or SW;
- current root manifest policy is V0.6.1 only after superseded manifests are deleted;
- package is re-extracted and package checksums are verified before delivery.

## Real-device acceptance checklist

1. Enter Golden Path and select any Focus.
2. Confirm all 78 facedown choices show the approved card-back artwork.
3. Select card 1; all unchosen cards must remain available.
4. Select card 2; remaining unchosen cards must remain available.
5. Select card 3; the deck stage must collapse and Reveal must become available.
6. Reveal the reading and confirm all three real card artworks and connected interpretation appear.
7. Tap each revealed card artwork and verify the correct enlarged card opens.
8. Verify Save and Share still operate.
9. Verify the Quiet Countdown appears after completion.
10. Leave and reopen Golden Path on the same local day; the same Focus, same three cards and same conclusion must restore.
11. Smoke-test Daily Guidance, Ask Ganesha and Three-Card Reading for normal entry/operation.
12. Confirm background audio behavior is unchanged.

Do not mark V0.6.1 real-device PASS until the corrected flow has actually been tested on device.
