- establishes Open Access + Voluntary Support as current business direction,
- keeps Buy Me a Coffee + PromptPay as simple support channels,
- defers login/member/subscription/backend architecture,
- upgrades localization into a permanent Global Native Language Standard,
- makes native-quality language completeness a release requirement,
- upgrades version/build/cache coherence into a hard release blocker,
- requires all live runtime markers to move together,

- updates roadmap to remaining core readings → Journal → Card Library → Support → Lucky Numbers → SFX/audio → reversals → production hardening,
