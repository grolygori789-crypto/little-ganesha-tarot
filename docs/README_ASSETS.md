# Little Ganesha Tarot — GitHub Asset Baseline V1

Studio: Benedict Interactive

This package contains only the currently approved production assets:

- `assets/cards/` — canonical 78-card deck, including the approved corrected versions of Four of Cups, Five of Cups, Seven of Pentacles, Eight of Pentacles, and Nine of Pentacles.
- `assets/ui/card-back.png` — approved master card back.
- `assets/ui/title-hero.png` — approved 9:16 title hero, using P'Benz's final brightness-adjusted version.
- `data/` — deck and UI asset manifests.

Older card-back or title-hero experiments are intentionally excluded.
