# V0.3.4 — Refined Sacred Motif Release Notes

This release replaces the first motif pass with a cleaner anchored symbolic system.

## Why this patch exists
The initial motif execution was too faint on real devices, some symbols felt visually awkward, and the home header spacing regressed on narrow screens.

## What changed
- rebuilt all Home motif SVGs with cleaner geometry
- changed motif placement from loose floating ornament to anchored decorative presence
- increased motif visibility moderately
- fixed Home header / intro spacing on narrow mobile layouts
- bumped build and service worker cache to 0.3.4

## Visual target
Premium, calm, sacred, readable, and intentionally understated.
