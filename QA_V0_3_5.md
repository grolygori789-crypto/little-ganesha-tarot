## QA honesty / final gate

This package has strong static, structural, and mocked-flow coverage. It is **not truthful to claim pixel-level real-browser visual QA before deployment**, because the final rendering depends on the actual Android/iOS browser, DPR, font loading, safe-area values, and GitHub Pages/service-worker state.

Therefore the final production gate remains:

1. upload/push V0.3.5,
2. wait for GitHub Pages deployment,
3. hard refresh / allow service-worker update,
4. inspect Home in Thai and English on the real device,
5. confirm motif visibility, typography, scroll header, Mini Player, Settings, and installed PWA behavior.

Until that device check is complete, status is **UPLOAD-READY / RUNTIME-VISUAL-PENDING**, not final production release.
